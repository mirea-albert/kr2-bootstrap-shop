## Описание проекта
Специализированный веб-ресурс центра автосимуляторов ropZ Sim Racing, знакомящий пользователей с кокпитами на базе прямого привода (Direct Drive), подвижными платформами 4DOF и шлемами виртуальной реальности. Сайт позволяет подобрать класс оборудования, изучить спецификации и оформить онлайн-заявку на заезд или корпоративный турнир.

## Используемые технологии
- HTML5 (семантическая разметка)
- CSS3 (кастомные стили автоспортивной тёмной темы)
- Bootstrap 5 (сетка, компоненты, адаптивность)
- Git / GitHub

## Способ подключения Bootstrap
Bootstrap подключён через CDN (версия 5.3.3) с подключением `bootstrap.bundle.min.js` перед закрывающим тегом body для обеспечения работы динамических компонентов (`collapse`, `modal`, `dropdown`, `accordion`). Кастомный файл стилей `css/custom.css` подключён строго после стилей фреймворка для переопределения визуальной темы.

## Реализованные Bootstrap-компоненты
- `navbar` — адаптивная навигация с выпадающим меню `dropdown` и бургером для мобильных экранов;
- `grid system` — 12-колоночная система с использованием `container`, `row`, `col-12`, `col-md-*`, `col-lg-*` и отступами `g-*`;
- `card` — карточки гоночных симуляторов с изображениями, фиксированной высотой `h-100` и тенями `shadow-sm`;
- `btn` — кнопки основного и вторичного действий (`btn-danger`, `btn-outline-light`, `btn-outline-danger`);
- `badge` — цветовые индикаторы статуса кокпитов (Direct Drive, Pro, Motion VR, Formula);
- `alert` — информационные блоки с правилами безопасности и инструктажа;
- `modal` — модальное окно экспресс-бронирования в один клик;
- `form-control`, `form-select`, `input-group`, `form-check` — адаптивная форма бронирования слотов с валидацией обязательных полей;
- `accordion` — раскрывающийся интерактивный блок FAQ с регламентом клуба;
- `breadcrumb` — хлебные крошки для навигации по каталогу и страницам симуляторов;
- `table` — стилизованная адаптивная таблица характеристик оборудования.
